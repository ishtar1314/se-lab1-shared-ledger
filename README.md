## 文件

- `requirements.md`：完整需求列表，按 REQ-001 起的稳定编号组织。
- `chat.txt`：访谈与补充沟通、AI 交互记录、审查记录。
- `report.pdf`：需求分析报告（3 页，按课程模板结构编写，包含背景概述、需求分析、非功能性需求、结论和附录）。
